# Mahallem — Seyrantepe Mahalle Gündemi

Seyrantepe Mahallesi (Kağıthane, İstanbul) için harita tabanlı ortak gündem uygulaması. Kullanıcılar mahalledeki aksaklıkları haritada işaretler; diğer kullanıcılar destek verip yorum yazabilir. Duyurular, destekler ve yorumlar Supabase veritabanında tutulur.
